# Политика источников базы знаний

Статус: **PROPOSED**, требует утверждения владельцем данных до публичного RAG.

## Единственный источник университетских фактов

Источником для индексации служит указанный владельцем GitHub-репозиторий, фиксируемый URL и commit SHA. Сейчас известен `https://github.com/eldiyar1710/robot-llm-3.11.26`; фактический URL источника в конфигурации P3 утверждается отдельно. Внешние нормативные сайты используются для проверки актуальности норм, но не добавляются в индекс автоматически.

PDF в репозитории не получает статус достоверного или разрешённого для публичного ответа только из-за наличия в GitHub. `Каталог знаний.pdf` описывает файлы и помогает классификации, но не заменяет сами источники для цитирования фактов.

## Классы и предварительная доступность

| Группа | Файлы | Предварительное правило |
| --- | --- | --- |
| Законодательство и правила РК | `1.pdf`–`22.pdf` | Индексировать с версией и датой проверки; актуальные правовые выводы — только после проверки статуса |
| Исторический акт | `5.pdf` | `superseded`, исключить из обычного ответа об актуальных правилах |
| Структура и сотрудники университета | `23.pdf` | Проверить актуальность и право публичного озвучивания имён/адресов |
| Внутренние правила университета | `24.pdf` | По умолчанию `internal_review`; публичные фрагменты утверждать отдельно |
| Студенческие процедуры | `25.pdf` | Проверить актуальность каждого шага и публичность перед включением |
| Каталог | `Каталог знаний.pdf` | `metadata_only`, не использовать как первичный источник фактического ответа |

Эта классификация стартовая; владелец данных утверждает её до P3. Статусы: `pending_review`, `active_public`, `active_internal`, `superseded`, `rejected`. Публичный запрос видит только `active_public`. Внутренний документ доступен оператору по роли, если такая роль утверждена.

## Метаданные и версии

Для документа: `document_id`, `source_path`, `source_url`, `source_commit`, `checksum_sha256`, `title`, `issuer`, `document_type`, `language`, `status`, `access_level`, `valid_from`, `valid_to`, `last_verified_at`, `ingested_at`, `metadata`. Для версии и каждого фрагмента хранятся страницы и модель embedding. Неизвестные даты не заполняются догадками.

Ингест проверяет допустимый путь, расширение, MIME/сигнатуру, размер, checksum и качество извлечения текста. Поддерживаемые форматы P3: PDF, DOCX, TXT, Markdown, JSON — только для реально присутствующих файлов и проверенных парсеров. Сканированные PDF требуют отдельного OCR-решения. Дубликаты по checksum связываются с исходниками; неизменённая версия не переиндексируется.

Приоритет при конфликте: подтверждённая действующая норма → утверждённое актуальное публичное правило университета в пределах своей компетенции → прочие утверждённые материалы. Если статус или область действия неясны, ответ сообщает о конфликте и не выбирает удобный вариант молча.

## Безопасность ответа

Фрагменты PDF — недоверенный ввод. Команды, просьбы раскрыть prompt или изменить роль, найденные в файле, игнорируются. Ответ может ссылаться только на конкретные страницы активных разрешённых версий. Для отсутствующего, устаревшего или конфликтного контекста — локализованный отказ или уточнение. Ссылки содержат `source_path`, commit/version и страницу.

До публичного запуска владелец данных должен утвердить перечень `active_public`, политику хранения истории вопросов и процедуру регулярной проверки изменяемых сведений (руководство, адреса, сроки, стоимость, контакты).

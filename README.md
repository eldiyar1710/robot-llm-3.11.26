> Исходный код API и команды запуска: [backend/README.md](backend/README.md). Архитектура и план дальнейших фаз находятся там же.

Исходные документы для базы знаний о высшем и послевузовском образовании Казахстана и внутренних процедурах Университета имени Ж. А. Ташенева. В репозитории находятся 25 исходных PDF и отдельный каталог с описанием части документов. Это исходные материалы для будущего поиска, индексации и ответов на вопросы; программная база данных здесь пока не создана.

## Использование в будущей базе знаний

Для каждого ответа сохраняйте ссылку на исходный PDF и страницу. Разделяйте нормативные акты РК и внутренние документы университета; для вопросов об университете учитывайте оба уровня правил. Перед применением правовых норм проверяйте актуальную редакцию и статус документа в официальном источнике. Данные о должностях, адресах, сроках и процедурах также могут изменяться. При индексации `5.pdf` помечайте как утративший силу.

Рекомендуемые поля записи документа: `file_name`, `title`, `issuer`, `document_type`, `language`, `topic`, `status`, `effective_date`, `source_url`, `last_checked_at`. Для фрагментов текста дополнительно храните `page_number` и ссылку на соответствующий документ.
